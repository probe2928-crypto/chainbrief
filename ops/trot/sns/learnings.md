# 트롯스테이지 SNS 배포 요령·성과 메모 (한 줄씩 누적)

- 11/04 파일 넣기(무료·내장 브라우저): 밴드 탭은 raw.githubusercontent.com fetch 가능(chainbrief 공개 저장소) → 밴드 탭에서 이미지 fetch→base64 → `location.href='https://www.facebook.com/...#trot='+encodeURIComponent('이름:base64')`로 이동 → 도착 페이지에서 `performance.getEntriesByType('navigation')[0].name`의 해시를 atob→File→DataTransfer로 input[type=file]에 넣기. 토큰 거의 안 듦(300KB 해시 OK). 페이지 새로고침되면 사라지니 다시 중계.
- 11/04 페북·인스타 캡션: 줄바꿈 있는 글은 '타이핑'이 깨짐 → 에디터 focus 후 ClipboardEvent('paste', text/plain) 디스패치로 넣기. 밴드는 타이핑 OK(사진 넣은 뒤 '태그 선택' 아래를 클릭해야 커서가 들어감).
- 11/04 페북 '게시물 만들기' 상단 'AI 레이블' → 켜기, 인스타 캡션 화면 'AI 레이블 추가' 토글 켜기 → 게시물에 'AI 콘텐츠' 표시됨. 인스타 자르기는 왼쪽 아래 아이콘 → '원본'(4:5 유지).
- 11/04 window.open은 같은 탭을 덮어씀(팝업 X) — 쓰지 말 것.
- 성과: 첫 게시 직후라 데이터 없음(팔로워 0). 다음 회차부터 반응 기록.
- 11/04 막힌 단계① 스튜디오 영상 확인: /videos/upload(동영상 탭)만 보면 '콘텐츠 없음' → 반드시 /videos/short(Shorts 탭)도 볼 것. 행 읽기는 `ytcp-video-row` innerText(마지막 칸 = 조회수).
- 11/04 막힌 단계② 밴드 글쓰기: 사진 첨부 후 첫 클릭이 '태그 선택' 버튼에 맞으면 타이핑이 통째로 사라짐 → 에디터 열자마자 JS로 contenteditable에 focus+커서 지정 후 타이핑. '게시' 활성화는 공백 '타이핑'으론 안 될 때가 있음 → 끝에 공백 2개 쳐 두고 Backspace 키 1번 누르면 `-confirm` 붙음. 게시는 `document.querySelector('._btnSubmitPost').click()`.
- 11/04 막힌 단계③ 밴드 공백 타이핑이 커서 위치(해시태그 중간)에 들어가 '#연 화'가 됨 → 공백 치기 전 JS로 커서를 맨 끝 텍스트 노드로 옮길 것.
- 11/04 페북 링크 게시물: 붙여넣은 글에 유튜브 주소가 있으면 3초 안에 미리보기 카드 자동 생성 — 따로 할 일 없음. 링크 게시물엔 AI 레이블 생략(글에 AI 표시 있음).
- 11/04 인스타 웹은 게시 직후 '완료' 대신 다른 곳 클릭하면 전체 새로고침될 때가 있어 중계해 둔 이미지(window 변수)가 사라짐 → 게시물마다 밴드 탭 해시 중계를 다시 할 것.
- 11/04 (제작 채팅) 인스타 **릴스 영상** 성공: 밴드 탭에서 `ig/<id>.mp4`(≤1MB) fetch→base64(32KB씩 String.fromCharCode)→`location.href='https://www.instagram.com/trotstage_kr/#trot='+encodeURIComponent('이름.mp4:'+b64)` (URL 1.37MB OK) → 도착 탭에서 navigation 해시→File(video/mp4). 만들기(+)→게시물→`[role=dialog]`의 마지막 input[type=file]에 DataTransfer → '릴스로 공유' 안내 확인 → '다음' 2번(JS로 innerText==='다음' 클릭) → 캡션 contenteditable에 paste 이벤트 → 'AI 레이블 추가' 줄의 input[type=checkbox] click → '공유하기' 클릭 → 약 30초 뒤 '릴스가 공유되었습니다'.
- 11/04 내장 브라우저 창이 좁으면 인스타 대화상자가 잘림 → resize_window 1280x860 후 작업, 끝나면 preset desktop으로 복구.
- 11/04 밴드 동영상: fetch(raw)→DataTransfer→`input[accept^="video"]` change → '동영상 올리기' 창의 'AI 활용' 토글 켜고 첨부하기. 영상 들어간 뒤 영상 위 빈 줄 클릭→ctrl+Home→캡션 타이핑 OK.
- 11/04 페북: 같은 해시 중계로 ig 파일을 페북 탭에 넣으면 영상 게시도 가능(시험 전). 링크 글은 '게시물 설정'에 '예약 옵션'이 있어 미리 예약 게시 가능.
- 11/04 내장 브라우저는 localhost/127.0.0.1 접속 불가(로컬 서버 릴레이 X), window.open 불가, 네이티브 파일창 안 뜸.
- 성과(11/04 03시 확인): eomma_1 3채널 모두 반응 0(밴드 표정·댓글 0, 페북 좋아요 0, 인스타 릴스 좋아요·댓글 0, 팔로워 0) — 아직 비교할 데이터 없음. 이번 회차 변수=페북 영상 직접 업로드(링크글 대비 비교 예정).
- 11/04 페북 영상 직접 업로드 성공: 밴드 탭 해시 중계로 ig 파일 → '무슨 생각을…' 클릭 → 창 안 '사진/동영상' 버튼(find로 두 번째 것) 누른 뒤 `[role=dialog]`의 input[type=file]에 DataTransfer → 캡션 paste → 'AI 레이블' 버튼은 JS로 `[role=dialog] [role=button]` 중 'AI 레이블'로 시작하는 것 click → '콘텐츠 레이블 지정' 창의 input[type=checkbox] click → '확인' → '다음'하면 '릴스 수정'→'다음'→'릴스 설정'(AI 레이블 켜짐 확인)→'게시'. 결과는 페이지 릴스 탭(&sk=reels_tab)에 /reel/ 링크. 주의: 좌표 클릭은 1280x860 에뮬 때 프레임이 800x537로 축소되니 스크린샷 기준 좌표로 계산(틀리면 창이 닫힘, 임시저장은 남음).
- 성과(11/04 05시 확인): dangsin_1 — 밴드 post/8 표정·댓글 0, 페북 직접 업로드 릴스 조회 16(eomma_1 링크글은 좋아요 0) → 페북은 영상 직접 업로드 유지. 인스타 릴스 댓글 0·팔로워 0. 이번 회차 변수=인스타 캡션 해시태그에 #AI가수 추가(나머지 동일).
