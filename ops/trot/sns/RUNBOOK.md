# 트롯스테이지 SNS 배포 런북 (2시간마다 1회 실행 → 하루 12회)

세준 지시(11/4): 유튜브 영상을 밴드·페북·인스타에 매일 10회 이상 올리고 디자인·영상 계속 고도화. 무료 방식(유료 도구 X), 세준 컴퓨터 **내장 브라우저**로 직접 게시.
먼저 `learnings.md`(요령·막힌 단계)를 읽고 그대로 따른다. 새로 알게 된 요령은 learnings.md에 한 줄 추가.

## 한 회차에 할 일 (소재 1개 → 3채널)
1. ops-status 브랜치 `ops/trot/sns/queue.json`, `posted.md`를 읽고 posted.md에 아직 없는 queue 첫 항목 1개를 고른다(같은 가수 3연속 금지).
   - 미디어(공개, trot-media 브랜치): 밴드용 30초 `clip`(≈3MB), 인스타용 15초 `ig`(≤1MB, `.../trot-media/ig/<id>.mp4`).
2. **밴드** https://band.us/band/104995766 — 글쓰기 → 동영상 첨부: 밴드 탭 JS에서 `fetch(clip)`→Blob→File(video/mp4)→DataTransfer→`input[type=file][accept^="video"]`에 넣고 change → '동영상 올리기' 창에서 **AI 활용 토글 켜기** → 첨부하기 → 영상 위 본문 클릭 후 캡션 타이핑 → 게시.
3. **페이스북 페이지** https://www.facebook.com/profile.php?id=61596061627297 — '무슨 생각을 하고 계신가요?' → 캡션(+ 해당 곡 유튜브 숏츠 주소, 모르면 채널 주소) → 다음 → 게시. 링크 미리보기 자동. (영상 직접 업로드는 learnings의 해시 중계로 가능하면 1MB 이하 ig 파일로 시도)
4. **인스타 @trotstage_kr** — learnings.md의 '밴드 탭 해시 중계' 방식으로 `ig/<id>.mp4`(1MB 이하)를 인스타 탭에 넣어 릴스로 게시. 캡션은 붙여넣기(ClipboardEvent paste), **AI 레이블 추가 켜기**. 실패하면 ⏸로 기록하고 다음 회차에 재시도.
5. `posted.md` '제작 채팅 운영분' 표에 한 줄 추가(시각·id·채널별 ✅/❌/⏸·링크·비고) → commit & push(ops-status, 충돌 시 rebase 후 두 쪽 내용 모두 보존).

## 큐가 떨어지면 (남은 항목 0)
- 영상 대신 **카드 게시물**로 이어간다: 가사 한 줄 카드·D-day 카드(메들리 11/6 금 18:30)·세 가수 질문 카드(고향·신청곡) 등. `src/`의 HTML을 복사해 문구만 바꾸고 Playwright로 1080x1350 JPG 렌더 → `assets/`에 커밋 → 같은 방식으로 3채널 게시. 같은 문구 반복 금지.
- 새 영상 클립은 트롯 제작 채팅에서 만든다(메들리 원본이 거기 있음).

## 고도화(매 회차 1가지만)
- 직전 게시물들의 반응(밴드 조회·댓글, 페북·인스타 좋아요·조회)을 확인해 learnings.md '성과' 줄에 기록. 잘 된 훅/가수/시간대 쪽으로 다음 소재 순서를 조정. 한 회차에 바꾸는 변수는 1개.

## 유튜브 링크 홍보 (11/4 세준 지시: 인스타에도 유튜브 링크 같이 홍보)
- 인스타: 캡션은 queue의 `caption_ig` 사용(풀버전 유튜브 주소 + '프로필 링크 클릭' + 채널 검색어). 인스타 캡션 링크는 눌리지 않으므로 반드시 '프로필 링크' 안내를 첫 3줄 안에 넣는다. 프로필 링크는 유튜브 채널(세준이 앱에서 설정)로 유지.
- 페북: `caption_fb`(곡 풀버전 링크 + 채널 링크) 사용 → 링크 미리보기는 풀버전 영상으로.
- 밴드: 기존 `caption` + 영상 아래 풀버전 링크 한 줄 추가(`yt_full`).

## 규칙
- 모든 게시물에 'AI로 제작한 가상 가수' 표시 + 플랫폼 AI 레이블. 실존 가수 이름 언급 금지.
- 같은 소재 재게시 금지. 결제·유료 기능·광고/게시물 홍보(부스트) 금지. 계정·페이지 설정 변경 금지. 댓글 답글 안 함(별도 지시 전까지).
- 하루(00~24시 KST) 채널별 12건 넘기지 않기.
- 내장 브라우저에 연결이 안 되면(컴퓨터 꺼짐·앱 닫힘) 아무것도 하지 말고 posted.md에 '오프라인 건너뜀'만 기록.
- 세준이 SNS 배포 중지를 말하면 이 예약 작업을 즉시 끈다.
