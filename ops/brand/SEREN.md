# SEREN 세렌 그룹 브랜드 규칙 (2026-11-04 세준 확정)

전 직원 공통 — 그룹 이름·로고가 들어가는 모든 디자인(사이트 푸터, 명함, SNS, 영상 엔딩)에 적용.

- 로고: `SEREN` 대문자, 서체 **Tenor Sans** (Google Fonts), 자간 0.2em. 아래 한글 `세렌 그룹`(자간 넓게, 작게).
- 심볼: 로고 위 가는 수평선 두 줄(긴 줄+짧은 줄). 작을 땐 생략 가능. 아이콘·명함 뒷면은 **SR 모노그램**(흰 S가 돌색 선 R 위에 겹침, 먹색 바탕).
- 명함: 국제 규격 85×55mm, 앞면 영문 이름 위·한글 아래(Sejun Park / 박세준 / CHAIRMAN & FOUNDER), 뒷면 먹색+SR. 코튼지 600g 레터프레스 권장.
- 컬러: 먹 #1E1E1E · 한지 #F6F3EE · 모래 #D9CFC0 · 돌 #8C8478 · 밤 #1C2A44. 장식·그라데이션 금지, 조용한 최고급.
- 계열사 표기: `SEREN / 계열사명` (같은 서체, 슬래시는 돌색). 예: SEREN / CHAINBRIEF, SEREN / QURATOR.
- 원본 시트: 디자인 캔버스 'SEREN 그룹 로고' → '최종 · SEREN 브랜드 시트'.
- 금지: ® 표시(상표 등록 전), 다른 회사 로고 흉내, 서체 임의 변경.
