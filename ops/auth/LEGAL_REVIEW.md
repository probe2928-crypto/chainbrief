# 회원가입·로그인 법적 검토 (2026-11-02, 실무이사)

## 4. 앱스토어

- **Apple 4.8**: 앱에 구글·카카오 같은 제3자 로그인을 넣으면 이름·이메일만 받고, 이메일 숨기기를 허용하고, 동의 없는 광고 추적이 없는 로그인 옵션을 함께 제공해야 함 → Sign in with Apple 포함. 근거 정리: https://9to5mac.com/2024/01/27/sign-in-with-apple-rules-app-store/
- **Apple 5.1.1(v)**: 계정 만들기가 있으면 앱 안에서 탈퇴(삭제) 시작 가능해야 함, 비활성화만으로는 불충분, Sign in with Apple 회원은 REST API 로 토큰 철회, 자동갱신 구독자는 Apple 결제가 계속된다는 안내 필요 → 탈퇴 화면에 구독 안내(`iapNotice`), 토큰 철회는 2단계 Edge Function. 근거: https://developer.apple.com/support/offering-account-deletion-in-your-app
- **Google Play**(QURATOR 앱): 계정 생성 앱은 앱 내 삭제 + 웹 삭제 링크를 데이터 보안 양식에 등록.

## 5. 남은 확인 (공개 전)

1. **운영 주체**: 다섯 사이트(QURATOR '회사', LUFT '루프트', 인생준준 '운영자', Perpline, 체인브리프)가 **같은 사업자(박세준 개인사업자)** 인지 확인 필요. 사업자가 다르면 통합 회원 DB 공유·교차 마케팅은 '제3자 제공'이 되어 별도 동의가 필요함. 지금 문구는 '같은 운영자' 전제.
2. **Apple 한국 개발자 서버 알림 주소**: 애플 문서에 한국 개발자는 새 Services ID 등록 시 Server-to-Server 알림 주소가 필요하다고 되어 있으나 Supabase 는 이 엔드포인트를 지원하지 않음 → 등록 화면에서 필수로 나오면 Edge Function 필요.
3. **카카오 연결 끊기**: 카카오싱크 정책상 탈퇴 시 unlink API 호출 필요 → Admin 키를 쓰는 Edge Function(2단계). 그 전까지 처리방침은 '계정 설정에서 직접 끊을 수 있음'으로만 적음.
4. **문자(SMS) 채널**: 가입 때 휴대폰 번호를 받지 않으므로 SMS 동의는 번호가 있는 경우(LUFT 주문 등)만 실효. 번호를 회원 정보로 받기 시작하면 수집 항목·목적 갱신 필요.
5. **Perpline**: 한국 거주자 대상이 아님 → GDPR 등 해외 법 검토는 하지 않음. 영문 고지만 준비.
6. 발송 업체 확정 시 각 처리방침 '추후 고지' 칸 업데이트(CRM 담당과 연결).
