# 체인브리프 고도화 로드맵

주 3회(월·수·금) 자동 점검 때 이 파일을 갱신한다. 위에서부터 우선순위. 끝낸 항목은 '완료'로 옮기고 날짜를 적는다.

## 사용자 조치 필요
- [ ] (결정) 국내 커뮤니티(디시·코인판)·거래소 공지는 GitHub 서버 접속을 막음(403) → 세준 PC에서 15분마다 수집해 푸시하는 방식 세팅 여부
- [ ] Supabase 프로젝트 생성 → `docs/supabase.sql` 실행 → `site.config.json` supabase 입력 (자유게시판 오픈)
- [ ] 도메인 구매 → DNS 설정 → Pages 커스텀 도메인 → `domain`, `app/capacitor.config.json` server.url 변경
- [ ] (선택) 저장소 Secrets에 `ANTHROPIC_API_KEY` → 해외 헤드라인 자동 번역
- [ ] Google Play 개발자 계정($25) / Apple Developer($99/년) → 스토어 출시
- [ ] 인터넷신문 등록(관할 시·도) 후 `footer.registration` 입력
