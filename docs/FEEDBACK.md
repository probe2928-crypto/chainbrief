## 고정 규칙 (세준이 정한 것 — 되돌리지 않는다)

- 롤모델: 코인니스(coinness.com). 기능·정보 구조·속도감은 배우되 문구·로고·디자인을 베끼지 않는다. 체인브리프의 프랑스 메종 톤은 유지.
- 메뉴 순서: 속보 → 뉴스 → 시세 → 급등 → 커뮤니티 → 프로젝트 → 문의 → 상장(맨 끝). 상장은 중요도가 낮다.
- 휴대폰: 위쪽 메뉴 줄 없음. 아래 탭(속보·뉴스·시세·급등·메뉴) + '메뉴' 시트로만 이동.
- 숫자: 가로획이 얇은 Bodoni 숫자 금지. 큰 숫자·코인 심볼은 Newsreader 600(--f-num), 작은 숫자는 Jost 500.
- 로고: 아이보리 바탕 Bodoni 이탤릭 C + 레드 점(2026-10-28). 예전 CB 사각 로고로 돌리지 않는다.
- 상장: 거래소 전체(업비트·빗썸·바이낸스·OKX·바이비트·코인베이스)를 한 목록으로. 국내/해외(코리아 리스팅) 따로 나누지 않는다(2026-10-29). 거래소·유형 필터로 거른다. 영어·중국어판 필터는 해외 거래소가 먼저. 토큰화 주식·주식 선물·바이낸스 알파는 넣지 않는다.
- 거래소 선택 시트(Perpline 페이백): 레퍼럴 코드는 어디에도 표시하지 않는다(링크로만 가입, 2026-10-29). 탭·분류를 누르면 3시간에 한 번 + 오른쪽 가장자리 반투명 버튼으로 언제든. 광고 유입(adclean)에는 숨김. 앱에는 거래소 레퍼럴을 넣지 않는다(스토어 정책).
- 오리엘 재단 대상은 '도움이 필요한 가정과 사랑스러운 아이들'. '동남아' 표현 금지.
