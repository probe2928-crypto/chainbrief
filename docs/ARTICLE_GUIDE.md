# 체인브리프 기사 작성 가이드 (스캇 박 기명 기사)

하루 3회(오전·오후·저녁) 발행. 국내외 블록체인·가상자산 이슈 중 **그 시간대 가장 중요한 이슈 1건**을 골라 기자가 쓴 해설 기사 1편을 쓴다.

## 주제 고르기
- 최근 12시간 안에 나온 뉴스 우선. 이미 이전 기사(`content/articles/`)에서 다룬 주제는 새 진전이 없으면 피한다.
- 국내(금융위·금감원·국회·업비트·빗썸·원화 스테이블코인 등)와 해외(SEC·CFTC·ETF·연준·대형 프로젝트·해킹 등)를 하루 안에서 섞는다. 오전 기사가 해외면 오후·저녁 중 하나는 국내.
- 단순 시세 등락은 주제가 되지 않는다. 시세는 이슈의 배경으로만 쓴다.

## 사실 확인 (가장 중요)
- 핵심 사실(누가, 무엇을, 언제, 수치)은 **서로 다른 매체 2곳 이상**에서 확인한다. 1차 출처(공식 발표, 공시, 보도자료, 법안 원문)가 있으면 그걸 우선한다.
- 확인되지 않은 건 쓰지 않는다. 숫자·날짜·직함은 확인한 그대로 쓴다.
- 사람이 하지 않은 말을 따옴표로 만들지 않는다. 인용은 출처에서 확인된 짧은 문장(15단어 이내)만, 기사당 최대 1~2개.
- 원문 문장을 그대로 옮기거나 구성을 따라 쓰지 않는다. 사실만 가져와 처음부터 새로 쓴다.

## 구성
```
title: 핵심을 담은 제목 (30자 안팎, 낚시성 금지)
summary: 리드 요약 1~2문장
```
본문 구조(소제목은 `##`):
1. **리드 문단** — 소제목 없이 시작. 추상적인 요약 대신 구체적인 장면·숫자·사람으로 연다. (예: "FATF가 집중 분석하기로 했다" ✕ → "한국 거래소들이 2022년부터 해 온 트래블룰이 처음으로 국제 시험대에 오른다" ○)
2. 본문 소제목 2~3개 — **그 기사 내용으로 직접 짓는다.** "무슨 일이 있었나", "논점", "시사점", "배경", "전망" 같은 틀 소제목은 쓰지 않는다. (예: `## 한국은 왜 대상에 들어갔나`, `## 트래블룰은 일찍 했지만`, `## 내년 6월까지 거래소가 할 일`) 짧은 기사는 소제목 없이 써도 된다.
3. 내용은 지금처럼 사실 → 엇갈리는 시각(한쪽 편 들지 않기) → 앞으로 볼 일정·변수 순서를 지키되, 틀을 드러내지 않는다.
4. 마지막 문단은 교훈·정리로 끝내지 않는다. 다음에 일어날 구체적인 일(날짜·결정·숫자)로 끝낸다.
5. 마지막 줄: `*본 기사는 정보 제공 목적이며 투자 권유가 아닙니다.*`
6. 그 아래 `**참고**` 다음 줄부터 출처 목록: `- [매체명 · 기사 제목](URL)` 2~5개.

## 문체 — 사람 기자가 쓴 것처럼 (세준 지시 2026-11-02: "너무 딱딱하게 컴퓨터가 쓴 것 같다")
- 신문 기사체(~했다, ~이다)는 유지하되, 옆자리 독자에게 설명하듯 자연스럽게. 1,200~2,000자.
- **문장 길이를 섞는다.** 짧은 문장 뒤에 긴 문장, 가끔은 한 줄짜리 문장. 모든 문장이 같은 길이·같은 리듬이면 기계 글이다.
- **어려운 말은 풀어 쓴다.** 전문용어는 처음 나올 때 한 번 쉬운 말로 설명하고 그다음엔 그냥 쓴다. 독자가 "그래서 나한테 뭐가 달라지는데?"를 바로 알 수 있게.
- **구체적으로.** "업계에 영향을 줄 수 있다" 대신 누가·무엇을·언제까지 해야 하는지. 숫자는 비교와 함께(예: "63억달러, 국내 1위 거래소 하루 거래대금의 두 배쯤").
- **문단 첫 문장을 매번 같은 방식으로 시작하지 않는다**("반면", "한편", "이처럼"으로 시작하는 문단 연속 금지).
- 쓰지 않는 말(기계 냄새 나는 상투어): 녹록지 않다, ~라는 뜻이다, ~라는 점에서, 주목된다/귀추가 주목된다, 무게가 실린다, 맞물린다, 시사하는 바가 크다, ~할 필요가 있다, ~의 일환으로, 본격화, 가속화, 결론적으로, 요컨대, 이처럼, 한편(문단 시작), ~로 풀이된다(근거 없이), ~할 것으로 보인다(한 기사에 1번까지), 의미 있는 행보, 새로운 국면, 업계 안팎.
- 과장·감탄·이모지 금지. "역대급", "폭등", "대박" 같은 말 금지. 가격 전망, 매수·매도 권유 금지.
- 영문 고유명사는 처음 나올 때 한글(영문) 병기. 예: 미국 증권거래위원회(SEC).
- **발행 전 소리 내어 읽기 점검:** 다 쓴 뒤 처음부터 끝까지 읽으며 ① 위 상투어 검색해서 0개로 ② 같은 어미가 3문장 연속이면 바꾸기 ③ 소제목이 틀 소제목이면 내용 소제목으로 ④ "사람 기자가 이렇게 말할까?" 어색한 문장 고치기. 이 점검은 생략하지 않는다.

## 형식
**심층취재** (`format: 심층취재`) — 한 주제를 깊게 판다. 2,800~4,000자.
- 리드(소제목 없이) → `## 배경` → `## 현장과 데이터` (수치·표·타임라인, 1차 자료 우선) → `## 쟁점` (이해관계자별 입장) → `## 전망과 체크포인트` → 면책 문구 → **참고** 4~8개.
- 표가 도움이 되면 마크다운 표 대신 문단으로 풀어 쓴다(사이트가 표를 렌더하지 않음). 숫자는 확인된 것만.
- 사실 확인은 서로 다른 출처 2곳 이상. 1차 자료(법안 원문, 공시, 보도자료, 온체인 대시보드, 공식 통계)를 최소 1개 포함.

**칼럼** (`format: 칼럼`) — 기자 개인의 관점을 담은 글. 1,800~2,600자.
- 제목은 주장이 드러나게. 첫 문단에서 문제 제기 → 근거 2~3개(확인된 사실) → 반론을 공정하게 소개 → 기자의 결론·제언.
- 1인칭은 최소화하되 "필자는" 정도는 허용. 특정인·특정 기업 비방, 확인 안 된 의혹 단정 금지. 투자 권유·가격 전망 금지.
- 끝에 면책 문구와 **참고** 2~5개.
