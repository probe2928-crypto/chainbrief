# CHAINBRIEF 유료 광고 (Bitmedia)

시작 2026-10-27. 영어판(/en/)과 중국어판(/zh/)을 각각 별도 캠페인으로 집행.

## 배너 (banners/)
- 언어 2(en, zh) × 테마 2(paper 흰 종이, noir 검정) × 10사이즈 = 40장, 모두 200KB 이하
- 사이즈: 728x90, 970x90, 468x60, 320x50, 320x100, 300x250, 336x280, 250x250, 160x600, 300x600
- 다시 만들기: `python3 ads/make_banners.py` (Bodoni Moda·Newsreader·Jost·Noto Serif/Sans CJK SC 폰트 필요)

## 문구 원칙
- 사실만: Upbit·Bithumb 상장을 15분마다 확인, 24시간 속보, 무료·가입 없음
- "모든 한국 상장" 같은 과장 금지(업비트·빗썸만 추적)
- 중국어는 홍콩·대만·싱가포르·말레이시아 독자 기준 "24小时" 사용(7×24 대신)
