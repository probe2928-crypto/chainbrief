# 체인브리프 시그널

펀딩비 급변 · 대량 청산 · 고래 이동 · 김프를 1분마다 확인해서 텔레그램으로 알려주는 봇 + 유료 구독(USDT TRC20) + 대시보드 API.

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/probe2928-crypto/chainbrief/tree/main/bot)

1. 텔레그램 @BotFather 에서 봇을 만들고 토큰 복사
2. 위 버튼 → Cloudflare 로그인(무료 가입) → 토큰·채널·결제 주소 입력 → Deploy
3. 배포가 끝나면 나오는 `https://chainbrief-signals.<이름>.workers.dev` 주소를 열면 설정 확인 페이지가 뜨고, 봇 연결이 자동으로 끝나요
4. 봇에게 `/claim <봇 토큰 마지막 6글자>` → 관리자 등록

자세한 내용: ../docs/SIGNALS_SETUP.md
