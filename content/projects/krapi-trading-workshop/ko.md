듣고 끝나는 세미나가 아니다. AI 커뮤니티 KRAPI가 여는 'AI 트레이딩 에이전트 빌드 워크샵'은 참가자가 각자 노트북을 펴고 직접 만든다. 11월 7일 토요일 저녁에 열리는 2주차에서는 거래소 API 키를 연결하고, 내 계정 상황을 한눈에 보는 트레이딩 대시보드를 완성하는 게 목표다.

## 한눈에 보기

- **일시** — 2026년 11월 7일(토) 오후 6시 30분~10시
- **장소** — 서울 강남구 역삼동 652-2 (오프라인 전용)
- **준비물** — 노트북. 간식과 음료는 주최 측이 준비한다.
- **신청** — 루마(Luma) 행사 페이지에서 참가 요청을 보내면 호스트가 승인한다.
- **주최** — KRAPI. AX(AI 전환) 컨설팅과 교육을 하는 AI 커뮤니티다. 호스트는 JEFF와 yangseungjun.

## 2주차에 하는 일

1주차에서는 AI 도구를 고르고 실제 쓰임새를 살핀 뒤, 각자 컴퓨터에 작업 환경을 깔았다. 2주차는 그 위에 손을 얹는 단계다.

순서는 두 가지다. 먼저 거래소에서 API 키를 발급받아 연결한다. API 키는 프로그램이 내 거래소 계정 정보를 읽거나 주문을 넣을 수 있게 해 주는 일종의 출입증이다. 그다음 이 연결을 바탕으로 개인 트레이딩 대시보드를 만든다. 잔고와 포지션을 매번 거래소 앱을 열지 않고 한 화면에서 보는 도구다.

에이전트에게 매매를 맡기기 전에 먼저 내 데이터가 어떻게 들어오고 보이는지부터 손으로 만들어 보는 구성이다.

## 누가 오면 좋나

AI 에이전트 이야기는 많이 들었는데 직접 붙여 본 적은 없는 트레이더, 거래소 API를 써 보고 싶었던 개발 입문자에게 맞다. 1주차를 놓쳤다면 신청할 때 호스트에게 미리 물어보는 편이 낫다. 환경 설정을 해 온 상태를 전제로 진행되기 때문이다.

참가비는 행사 페이지에 따로 적혀 있지 않다.

## 가기 전에 챙길 것

실습에서 API 키를 만들 때는 **출금 권한을 끄고**, 가능하면 접속 IP를 제한해 두자. 키가 외부에 노출돼도 돈이 빠져나가지 않게 막는 가장 기본적인 방법이다. 키는 화면 공유나 채팅창에 붙여 넣지 않는다. 자동매매나 AI 트레이딩은 원금 손실이 날 수 있다는 점도 잊지 말자.
