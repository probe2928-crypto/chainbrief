## What week 2 covers

Week 1 was about choosing AI tools, looking at real use cases and setting up a working environment. Week 2 puts that setup to work.

First, each participant issues an API key on an exchange and connects it. An API key is a pass that lets software read your account or place orders on your behalf. Then you build a dashboard on top of that connection, so balances and positions sit on one screen instead of in the exchange app.

The idea is to see how your own data flows in before handing any trading decisions to an agent.

## Before you go

When you create the key in the session, **switch off withdrawal permissions** and restrict it by IP where the exchange allows it. Never paste a key into a shared screen or a chat window. There is no price listed on the event page. Automated and AI-driven trading can lose money.
